# MUSIC BOX V8.5.5 — بسته‌ی انتشار با واسط LRCLIB

این بسته شامل برنامه‌ی MUSIC BOX و یک Vercel Function به نشانی `/api/lrclib` است. واسط فقط درخواست‌های خواندنی `get` و `search` را به LRCLIB عبور می‌دهد و URL دلخواه از کاربر نمی‌پذیرد.

## چرا این بسته لازم است؟

خطای مرورگر `Failed to fetch` یعنی درخواست از سمت مرورگر به پاسخ قابل‌خواندن نرسیده است. در این نسخه، برنامه ابتدا از مسیر هم‌دامنه‌ی `/api/lrclib` استفاده می‌کند؛ بنابراین مرورگر فقط با دامنه‌ی خود MUSIC BOX ارتباط می‌گیرد و Vercel Function از سمت سرور با LRCLIB تماس می‌گیرد. اگر این route در هاست موجود نباشد، برنامه اتصال مستقیم را هم امتحان می‌کند.

## انتشار روی Vercel

### اگر MUSIC BOX از قبل روی Vercel و دامنه‌ی ثابت منتشر شده است

1. از اطلاعات سایت فعلی یک فایل MBX بگیر و نسخه‌ی قبلی `index.html` را جدا نگه دار.
2. فایل `index.html` این بسته را در ریشه‌ی پروژه‌ی فعلی جایگزین کن.
3. پوشه‌ی `api` این بسته را در ریشه‌ی همان پروژه کپی کن؛ مسیر نهایی باید `api/lrclib.js` باشد.
4. تغییرات را روی همان پروژه و همان دامنه deploy کن. با حفظ origin، IndexedDB قبلی همان مرورگر در دسترس می‌ماند.
5. پس از انتشار، این مسیر را در مرورگر باز کن: `https://YOUR-DOMAIN/api/lrclib?resource=search&q=still%20alive`. پاسخ معتبر باید JSON باشد و در Headers مقدار `x-music-box-lrclib-proxy: 1` دیده شود.
6. سپس وارد MUSIC BOX شو و در پنل Lyrics گزینه‌ی «تست اتصال» را بزن. پیام موفقیت باید عبارت `Vercel relay` را نشان دهد.

### اگر روی دامنه یا پروژه‌ی جدید deploy می‌کنی

origin جدید حافظه‌ی IndexedDB قبلی را به‌صورت خودکار نمی‌بیند. ابتدا از origin قدیمی بکاپ MBX بگیر؛ بعد روی سایت جدید بکاپ را Restore کن.

## اجرای محلی

بازکردن HTML با دوبارکلیک (آدرس `file://`) برای مسیر واسط کافی نیست. برای تست کامل باید پروژه را با Vercel CLI اجرا کنی تا Function در `/api/lrclib` نیز فعال باشد.

## رفتار و محدودیت‌ها

- هیچ API Key یا secret لازم نیست.
- فقط GET و فقط endpointهای `get` و `search` مجازند.
- پارامترهای مجاز: `q`, `track_name`, `artist_name`, `album_name`, `duration`.
- پاسخ‌های موفق برای مدت کوتاه در edge cache می‌شوند؛ خطاهای 429 و 503 cache نمی‌شوند و `Retry-After` حفظ می‌شود.
- اگر خود Vercel هم نتواند به LRCLIB وصل شود، تابع خطای 502 یا 504 برمی‌گرداند؛ در آن حالت باید لاگ Function یا دسترسی upstream بررسی شود.

## قابلیت‌های DJ Pro در همین نسخه

- Auto Draft و Session قابل‌ویرایش در IndexedDB
- فایل مستقل `.mbdj` همراه فایل‌های صوتی هر Deck
- بکاپ MBX که پیش‌نویس جاری را پیش از ساخت آرشیو ذخیره می‌کند
- ذخیره‌ی خروجی صوتی MP3 یا WAV (در صورت نبود انکودر MP3، WAV به‌عنوان master نگه داشته می‌شود)
- تبدیل فایل ضبط‌شده به MP3/WAV از بخش ضبط‌ها و میکس‌ها
- افزودن ضبط WAV یا MP3 به کتابخانه بدون تبدیل اجباری

**قبل از جایگزینی نسخه‌ی فعلی، MBX بگیر و V7/V8.5.4 را نگه دار.**
